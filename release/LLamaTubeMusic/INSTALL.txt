LLamaTubeMusic: install without npm

1. Unzip this folder anywhere you keep apps (keep the folder; Chrome reads it from there).
2. Open chrome://extensions and turn on "Developer mode" (top right).
3. Click "Load unpacked" and select the LLamaTubeMusic folder (the one that contains manifest.json).
4. Reload music.youtube.com.

Shortcut: Alt+Shift+L shows or hides the window.
To update: unzip the new version over this folder, then click the reload icon on the extension card.
